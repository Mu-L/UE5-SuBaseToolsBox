## 材质属性转移工具新增"输出类型"两个互斥勾选框（支持材质类）

### 需求
- 被转换的源材质除材质实例外，也支持材质类（UMaterial；源选择已通过 UMaterialInterface 兼容，无需改）
- 新增两个互斥勾选框：① 转换后统一生成材质类 ② 转换后统一生成材质实例
- 两个都不勾选 → 按源类型生成（实例→实例，材质类→材质类）

### 关键引擎 API 调研（F:\UE_5.8\Engine）
- `UMaterial` 有 `SetScalar/Vector/TextureParameterValueEditorOnly`（Material.h:1489-1491），可设基础材质参数默认值
- 基础材质（UMaterial）**没有父材质概念**（`Parent` 只在 UMaterialInstance 上，MaterialInstance.h:647，公有 UPROPERTY）
- `UMaterialFactoryNew` 存在（Editor/UnrealEd/Classes/Factories/MaterialFactoryNew.h），但本功能用 DuplicateObject 复制母材质而非 factory
- `GetScalar/Vector/TextureParameterValue` 在 UMaterialInterface 上（读取侧通用）；editor-only SetXxx 只在子类（UMaterial / UMaterialInstanceConstant）上，需按类型分发

### 实现要点
- **生成材质类**做法：`FindBaseMaterialTemplate()` 向上追溯母材质链（UMaterialInstance::Parent 公有）找到最底层 UMaterial，再 `DuplicateObject<UMaterial>(Template, Pkg, Name)` 复制其材质图，然后 `ApplyParameterValues` 把源参数值烘焙进副本默认参数；基础材质无法挂父级，用"复制母材质+烘焙值"实现独立材质类
- 改名：实例→`原名_INST`，材质类→`原名_MAT`，避免同路径同名冲突
- `MakeUniqueAssetName()` 复用 FindObject<UPackage>+FPackageName::DoesPackageExist 做同目录唯一命名，规避命名冲突（Import_MM 同类教训）
- 三个辅助方法：`FindBaseMaterialTemplate` / `MakeUniqueAssetName` / `ApplyParameterValues`（按 UMaterialInstanceConstant / UMaterial 分发 setter）
- 开始日志补充输出类型；两个开关写入/读取配置 JSON（ForceGenerateMaterial / ForceGenerateInstance）
- 互斥逻辑：两个 CheckBox 的 OnCheckStateChanged 互相取消

### 注意 / 局限
- "生成材质类"依赖母材质能追溯到 UMaterial（典型情况母材质就是基础材质）。若母材质是实例且无基础材质父级，会跳过并日志提示
- 头文件仍是 `MaterialTttributeTransfer.h`（Tttribute 拼写）；.cpp 在 `MaterialAttributeTransfer/`
