# 2026-07-23 工作日志

## 批量材质球生成工具（SSpawnMaterial）实现

### 背景
用户要求在 SpawnMaterial 工具界面实现：从内容浏览器获取选中的纹理贴图，按命名关键词自动分类贴图通道，生成材质球。功能参考 Import_MM 但不修改其代码。

### 改动文件
1. **ToolsBox.Build.cs** — PublicDependencyModuleNames 新增 `"ContentBrowser"` 模块依赖
2. **SpawnMaterial.h** — 完整类声明（SSpawnMaterial : SCompoundWidget）
3. **SpawnMaterial.cpp** — 完整实现

### 核心设计
- **顶部功能说明文本**：标题 + 工具描述 + 使用方法 + 关键词对照表
- **贴图获取**：通过 `FContentBrowserModule::Get().GetSelectedAssets()` 获取内容浏览器选中资产，过滤为 UTexture2D
- **关键词匹配**：复用 Data.h 中的 TextureMatch 命名空间（BC/N/EM/OP/ORM/AO/R/M），不修改 Import_MM
- **贴图分组**：以 BC 贴图为锚点，剥离 BaseColor 后缀得到材质基础名，多组时按 CleanPrefix 过滤
- **材质生成两种模式**：
  - 母材质连线模式：创建 UMaterial + TextureSample 节点 + ConnectMaterialProperty，支持 ORM 通道分别连接
  - 父材质实例化模式：Duplicate 父 MI + SetStaticSwitchParameter + SetTextureParameterValueEditorOnly
- **ORM 适配**：自动检测是否存在 ORM 贴图，分别走 WithORM / WithoutORM 路径
- **通用父材质生成**：OnCreateGenericMaterialClicked 创建带静态开关的三级回退母材质
- **日志格式**：纯文本 `[HH:MM:SS] message`，无 RichTextBlock 标签（避免 Import_MM 中出现的标签泄露问题）

### 技术要点
- Data.h 中的共享定义（ChannelKey/TextureMatch/FChannelMeta/SwitchParam/TextureParam/EngineDefaults）被两个工具复用
- 资产名唯一性检查：DoesAssetExistInPath + MakeUniqueAssetName（FindObject + AssetRegistry 双重检查）
- SObjectPropertyEntryBox 用于父材质实例选择，需 PropertyCustomizationHelpers.h

- 优化匹配算法（核心名提取）：导入后贴图/模型名有多层前缀（导入前缀+原名+贴图后缀/拆分子部件名），旧逻辑用完整名 Contains 匹配会失败。新逻辑：1) ExtractCoreName 从材质key和模型名中都用同一套规则提取「核心名」——剥离 M_/MI_ 前缀和贴图后缀后取最后一个下划线右侧部分；2) 主匹配：材质核心名 == 模型核心名（精确比对）；3) 次匹配：模型名按下划线拆段后检查是否有完整段等于材质核心名（整段匹配，非子串）；4) 单材质时全赋予未匹配模型。**彻底删除子串 Contains 匹配**——之前 `SM_BalconyDoor_Framk` 因 BalconyDoor 包含子串 "door" 被误匹配到 Door 材质
- 集成命名规则系统（参考 Import_MM 不改其代码）：1) SpawnMaterial.h 新增 `EAssetType` 枚举 + `FSpawnNamingWidgets` 结构体 + `NamingControlMap` 成员 + `CreateNamingRow`/`GetAppliedName`/`StripNamingAffixes` 函数；2) UI 新增「资产命名详细规则」可折叠区域，可为 模型/贴图/材质/材质实例 分别配置前缀后缀（默认前缀勾选 SM_/T_/M_/MI_，后缀不勾选）；3) OnGenerateClicked 中生成材质前先用 `StripNamingAffixes(MatNameBase, Texture)` 剥离贴图前缀（如 T_Door → Door），再用 `GetAppliedName` 加材质前缀（如 M_Door），避免叠两层前缀 M_T_Door；4) GenerateMaterialWithoutORM/WithORM 中所有 `TEXT("M_")+BCRawName` → `GetAppliedName(BCRawName, EAssetType::Material)`，`TEXT("MI_")+BCRawName` → `GetAppliedName(BCRawName, EAssetType::Instance)`；5) ExtractCoreName 改为用 `StripNamingAffixes` 依次剥离 Material/Instance/Mesh/Texture 前缀后缀，感知用户配置而非硬编码
